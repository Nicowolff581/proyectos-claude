# Loli's Küche

Página de pedidos de salchichas alemanas. Abre `index.html` en el navegador.

- **Tienda** al estilo de una tienda en línea: tarjetas con foto, ingredientes, presentación y precio, botón «Añadir al carrito», filtros (Todas · Paquetes de 3 · Paquetes de 400 g) y «Ordenar por».
- El carrito (arriba a la derecha) cuenta los paquetes, y en «Pedidos» se arma el mensaje de WhatsApp con el total.
- Imágenes: `logo.png` (logo completo), `logo-mark.png` (ícono del menú) y `abuelo.jpg`.
